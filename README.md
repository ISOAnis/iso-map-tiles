# ISO map tiles

Pre-drawn map tiles for the ISO app's game-style map, served with GitHub Pages:

    https://isoanis.github.io/iso-map-tiles/nyc/{z}/{x}/{y}.png

256 px PNG tiles, zoom 9 to 14, standard XYZ scheme. They are generated by
`tools/map-tiles` in the iso-mobile repo, so don't edit them by hand. To
restyle, rebuild there and replace the city folder here (or add `nyc-v2` and
point `MAP_TILES.url` at it, so phones don't keep old cached tiles).

Data: US Census Bureau cartographic boundary and TIGER/Line files (public
domain). Labels set in Bebas Neue (SIL Open Font License).
